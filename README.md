# H17X 34 Programming Foundations (Python) - exercise list

## Exercises for H17X34 Programming Foundations

### Simple input/output/if-else statements

1. Write a program that asks the user to enter their name – then output a message on the screen saying **"Hello <name>"**.

2. Write a program that asks the user for their firstname and secondname in separate inputs – then concatenate both strings in an output saying **"Hello <firstname> <secondname>"**.

3. Write a program that asks the user how old they are.  
   - If they are 18 or over, output: **"Welcome to the nightclub"**  
   - If they are under 18, output: **"Sorry, you are too young to attend our virtual nightclub"**

4. Ask the user for the length and breadth of a floor – calculate the area of the floor – and output to the screen with a suitable message.

5. Ask the user what their favourite class is.  
   - If they say `"Python"`, output: **"I’m glad you chose that option"**  
   - Otherwise output: **"Oh, really, what about Python?"**

6. Write a program that asks how many bags of grit they would like (they cost £6 each).  
   - If they order more than 6 bags, **do not** include post and packing in their total  
   - Post and packing cost is £3

7. Write a program that asks the user how many cars they sold that day.  
   - For every car sold, they receive **£100 commission**  
   - If they sell more than 10 cars, they also receive a **£150 bonus**  
   Output their commission and bonus on the screen.

8. Write a program that translates 3 different words into another language (e.g., French).  
   When the user enters one of the three English words, output the French translation on the screen.

9. Ask the user what score they got in an exam, then output:  
    - Over 80: **"You have a very high score"**  
    - Between 50 and 79: **"You have done quite well"**  
    - Below 50: **"You will need to study a bit more"**
